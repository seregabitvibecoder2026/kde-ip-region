# IP Region: виджет для панели KDE Plasma 6

Показывает на панели значок глобуса и двухбуквенный код страны твоего внешнего IP
(например `IE`, `DE`, `RU`). Выглядит так же, как KVitals: моноширинный шрифт,
иконка 12px, цвета берутся из темы.

- **Клик** по виджету: проверить заново сразу.
- **Наведение**: флаг, город, IP, провайдер и время последней проверки.
- Проверка идёт раз в 15 секунд (меняется в настройках виджета).
- `··` значит, что идёт первая проверка. `--` или полупрозрачный код значит, что
  проверка не удалась, а на экране последнее известное значение.

## Безопасность

- Только HTTPS: ipinfo.io, затем ipwho.is, затем api.country.is (если первый не
  ответил, пробуется следующий). Голого HTTP нет, поэтому подделать ответ в сети
  не получится.
- Виджет не запускает команд и скриптов, ему не нужны root и sudo. Он делает
  только GET-запрос из QML, без кук и без своих заголовков.
- Ставится в домашнюю папку (`~/.local/share/plasma/plasmoids/`), систему не
  трогает.
- Что нужно понимать: эти сервисы видят твой внешний IP (тот же, что видит любой
  сайт). Через VPN они видят IP VPN-сервера.

## Установка на другой ноут (NixOS + Plasma 6)

1. Скачай и установи (git на NixOS по умолчанию нет, поэтому через `nix-shell`):
   ```bash
   nix-shell -p git --run "git clone https://github.com/seregabitvibecoder2026/kde-ip-region ~/kde-ip-region"
   ~/kde-ip-region/install.sh
   ```
   `install.sh` ставит виджет (или обновляет, если он уже стоит) и перезапускает
   панель. `kpackagetool6` уже есть в системе, если включён
   `services.desktopManager.plasma6.enable = true;`.
2. Правый клик по панели → **Добавить виджеты…** → найди **IP Region** →
   перетащи на панель рядом с KVitals.

### Обновление
```bash
cd ~/kde-ip-region && nix-shell -p git --run "git pull" && ./install.sh
```

### Удаление
```bash
kpackagetool6 -t Plasma/Applet -r org.kde.plasma.ipregion
```

## Настройки
Правый клик по виджету → **Настроить IP Region…**: интервал проверки, показывать
ли иконку, размер иконки, шрифт, размер шрифта, жирность.
